## 1. 项目概述

### 1.1 背景

BaiduPCS-Go 是功能完整的百度网盘第三方命令行客户端,但无图形界面,只在安装它的那台机器上可用。用户希望:程序跑在本地 Linux 服务器上,家庭成员/同事在局域网其他电脑上打开浏览器即可获得接近官方图形客户端的体验(浏览、上传、下载、分享等)。

两个结构性约束决定了架构:
1. **下载必须由服务器中转**:浏览器无法自定义 User-Agent,而百度 dlink 直链必须伪装 `netdisk` UA 才能不限速/不 403,故下载流量必然经过本地服务器流式转发,浏览器无法"绕过"本地直连百度。
2. **上传采用临时落盘**:浏览器→服务器→百度之间无法做到全流式(上传引擎需要文件大小与 MD5 秒传探测),故上传文件先落服务器临时目录,复用 BaiduPCS-Go 上传引擎,成功后立即删除。

用户的原始设想("别的电脑只把本地当壳子、实际去请求官方")经调研被部分否定:轻量 API(列表/搜索/分享等)经服务器转发没有区别;但**下载**因 UA 伪装问题必须中转。此结论已写入 D2。

### 1.2 目标

- G1:覆盖 BaiduPCS-Go 全部 CLI 能力(以 v4.0.2 README 命令清单为准),除明确降级项(见 3.12)外无功能缺失。
- G2:浏览器体感接近官方图形客户端:文件树浏览、拖拽上传、点击下载、进度实时可见、错误有中文提示。
- G3:单二进制交付:`linux/amd64` 与 `linux/arm64` 各一个,前端资源内嵌,解压即用,无外部依赖。
- G4:本地机器不留存用户数据:下载为流式直通(不落盘),上传临时文件在任务终态后 10 秒内删除。

### 1.3 范围边界(明确不做的)

- 不做 BaiduPCS-Go 未提供的功能(如百度官方客户端的音视频转码播放)。
- 不做多用户/权限体系(见 D1,单口令)。
- 不做 iOS/Android 原生 App;移动浏览器可用性为"尽力而为",不写验收指标。
- 不提供超出官方/上游客户端的下载提速承诺(受百度账号限速策略约束)。
- 不做公网暴露方案(HTTPS/反代/端口映射配置属部署方自担,见 D8)。

## 2. 用户故事

- US-01 作为**局域网用户**,我在浏览器输入 `http://<host>:8080`,输入口令后看到网盘文件树,像用官方客户端一样浏览。
- US-02 作为**用户**,我拖拽多个文件/整个文件夹到浏览器窗口,看到上传队列、每个任务的百分比与速度,上传完成后网盘列表自动刷新。
- US-03 作为**用户**,我点击一个 4GB 视频文件的下载按钮,浏览器开始下载且能暂停/续传,本地服务器磁盘占用不因我的下载而增长。
- US-04 作为**用户**,我把一个分享链接(含提取码)粘贴进转存框,选择目标目录后一键转存,转存结果直接出现在我的网盘里。
- US-05 作为**用户**,我粘贴磁力链/种子文件创建离线下载任务,在任务列表里看到进度,任务完成通知我。
- US-06 作为**多账号用户**,我在顶栏下拉里切换百度账号,切换后整个界面(配额、文件树、分享列表)反映新账号的数据。
- US-07 作为**用户**,我误删文件后到回收站页还原它;也能永久删除或清空回收站(有二次确认)。
- US-08 作为**用户**,我在搜索框输入关键字递归搜索全盘文件名,结果可点击跳转到所在目录。
- US-09 作为**服务器主人**,我下班关掉浏览器,第二天打开,未完成的传输任务仍在队列中(上传)或可重新发起(下载)。
- US-10 作为**服务器主人**,我在设置页修改下载并发/保存临时目录/限速等配置,立即对后续任务生效。
- US-11 作为**用户**,我粘贴一个分享链接(含提取码),浏览分享内容后勾选文件点下载按钮,文件经短暂临时转存直接下载到我的电脑,下载完成后网盘里不留任何内容、不占配额。

## 3. 功能需求

### 3.1 账号与配额(FR-01~05)

每条 FR 统一格式:**描述 / 输入 / 输出 / 异常分支 / 验收标准(二元可判)**。

**FR-01 百度账号登录**
- 描述:支持两种方式登录,映射上游 `login -cookies=<Cookies>` 与 `login -bduss=<BDUSS> -stoken=<STOKEN>`;上游"交互式用户名密码登录"已不被上游推荐且需验证码,Web 端降级不提供(见 3.12)。
- 输入:粘贴完整 Cookie 串,或 BDUSS+STOKEN 两个字段。
- 输出:登录成功,账号昵称出现在顶栏;凭证加密/受限权限存于服务器本地数据目录(0600),浏览器响应中不回显凭证明文。
- 异常:凭证无效 → 提示"凭证无效或已过期,请重新获取";STOKEN 缺失(仅 BDUSS)→ 提示必须同时提供 STOKEN。
- 验收:①粘贴含 BDUSS+STOKEN 的有效 Cookie 串登录后,`who` 接口返回该账号昵称;②提交乱串时返回 401 且中文错误提示;③登录后用浏览器开发者工具查看任意响应体,搜不到 BDUSS/STOKEN 明文。

**FR-02 账号列表与当前账号**
- 描述:映射 `loglist` + `who`,设置页展示全部已登录账号(uid/昵称/在线状态),顶栏显示当前账号。
- 验收:登录 2 个账号后,列表恰好显示 2 条且当前账号有高亮标识;凭证文件中账号数与列表一致。

**FR-03 切换账号**
- 描述:映射 `su <uid>`;顶栏下拉选择目标账号,一键切换。
- 行为:切换后服务器侧会话上下文(工作目录、任务归属)整体切到新账号;**进行中的传输任务不中断**,完成后按各自账号凭证提交。
- 异常:目标账号凭证失效 → 切换失败,当前账号不变,提示重新登录该账号。
- 验收:有任务传输中时切换账号,任务完成且新账号的浏览/上传均指向新账号数据;切到失效账号时返回错误且界面仍显示原账号。

**FR-04 退出账号**
- 描述:映射 `logout`;仅从本地凭证库移除,并要求二次确认(与上游"确认防误操作"对齐)。
- 异常:该账号有进行中任务 → 阻止退出,提示"请先取消 N 个进行中任务"。
- 验收:无任务时退出后 `loglist` 少一条;有任务时退出请求被拒绝且返回任务计数。

**FR-05 网盘配额展示**
- 描述:映射 `quota`;顶栏或侧栏常驻显示总容量/已用/百分比,每 60 秒或每次上传完成时刷新。
- 验收:接口返回值与上游 CLI `quota` 输出一致(字节级);上传 1GB 文件完成后 60 秒内已用数值增加约 1GB(误差 ≤2%,含秒传为 0 增长两种情况都算通过)。

### 3.2 文件浏览与检索(FR-06~10)

**FR-06 目录浏览**
- 描述:映射 `ls <目录>`;文件树界面,显示名称/大小/修改时间/类型图标,支持名称、大小、时间三列排序(升/降序)。
- 输入:目录路径(点击目录进入或面包屑跳转)。
- 输出:该目录下的直接子项列表(延迟加载,不预取整棵树)。
- 异常:目录不存在或被百度屏蔽 → 中文提示,界面回退到上一有效目录。
- 验收:①对含 >1000 个对象的目录(v4.0.2 已支持)能完整分页加载;②点击大小列头两次,列表按大小降序再升序;③访问不存在路径返回 404 语义的中文提示且不掉出当前目录。

**FR-07 路径导航与工作目录**
- 描述:映射 `cd`/`pwd`;面包屑路径条 + 后退按钮;服务器为每个 Web 会话维护网盘工作目录(首次登录默认 `/`)。
- 验收:连续进入 3 层目录后点面包屑第 1 层,列表正确;刷新页面后仍停留在刷新前目录。

**FR-08 树形视图**
- 描述:映射 `tree <目录>`,作为可选视图,支持设定最大展开层数(默认 2 层,避免大目录卡死)。
- 验收:对 ≥3 层嵌套目录生成树;max_depth=2 时第 3 层节点显示为可展开占位符而不发起请求。

**FR-09 元信息查看**
- 描述:映射 `meta <路径>`;右键/详情按钮弹出面板,展示完整元信息(大小、MD5、fs_id、创建/修改时间、是否目录)。
- 验收:面板中 MD5 与 `meta` CLI 输出一致;目录与文件两种类型都能正常展示。

**FR-10 搜索**
- 描述:映射 `search [-r] <关键字>`;搜索框支持关键字 + 范围目录(默认当前目录)+ 递归开关。
- 说明:上游仅支持按文件名搜索且**不支持匹配目录**,界面文案需注明"仅匹配文件名"。
- 输出:结果列表(名称、所在目录、大小、时间),点击"跳转"导航到所在目录并高亮该文件。
- 验收:①在根目录递归搜索能返回子目录中的文件;②纯目录名关键字返回空结果集并提示"不支持搜索目录";③结果点击跳转后高亮正确。

### 3.3 下载(FR-11~14)

**FR-11 流式下载代理(单文件)**
- 描述:映射 `download <文件>`;浏览器发起下载 → 本地服务器以 `netdisk` UA 向百度 dlink 发起请求 → **流式**回传给浏览器,本地不落盘(仅固定大小环形缓冲,≤32MB)。
- 输入:网盘文件路径;HTTP 头支持标准 `Range`。
- 输出:HTTP 200/206 响应,带 `Content-Length`、`Accept-Ranges: bytes`、`Content-Disposition`(RFC 5987 编码中文文件名)。
- 异常:百度侧断流 → 服务器对百度重新建连并按 Range 续取(对浏览器透明,浏览器侧连接不断);dlink 获取失败 → 返回 502 + 中文错误。
- 验收:①下载 1GB 文件过程中,`du` 监控临时目录增长 ≤32MB;②用 `curl -H "Range: bytes=1000-1999"` 恰好收到 1000 字节且内容偏移正确;③下载中用浏览器断开重连(带 Range),从断点继续而非重头;④`Content-Disposition` 中文件名在 Chrome/Firefox 下载对话框中显示正确中文。

**FR-12 目录/多选递归下载**
- 描述:映射"下载目录";前端把目录展开为文件清单逐个走 FR-11,打包为浏览器侧多个下载任务(浏览器下载队列天然支持);**服务器不做 zip 打包**(zip 需要顺序读流+缓存,破坏"不落盘"目标)。
- 说明:目录选中下载时,前端提示"共 N 个文件,将逐个下载"。
- 验收:选择含 3 层嵌套、共 5 个文件的目录,触发后浏览器收到 5 个独立下载,相对路径通过 `Content-Disposition` 保留(浏览器会因安全策略扁平化,由前端在下载记录中展示原始相对路径)。

**FR-13 秒传状态展示(下载侧)**
- 描述:`export`/秒传链接生成入口(映射 `export <文件>`),在详情面板输出秒传链接文本;界面上注明上游声明"秒传转存已不被官方支持,成功率不作承诺"。
- 验收:对任意文件能生成格式正确的秒传串(含 MD5/切片 MD5/长度/文件名四段);界面固定展示风险声明文案。

**FR-14 下载并发与限速**
- 描述:服务器侧全局限速/并发参数(见 FR-34)对下载代理生效;单浏览器连接占 1 个直链,同账号并发直链数默认 ≤3(超出的排队)。
- 验收:发起第 4 个下载时前 3 个不受影响且第 4 个状态为"排队中";设置限速 1MB/s 后实测速率 ≤1.05MB/s(持续 30 秒均值)。

### 3.4 上传(FR-15~17)

**FR-15 浏览器上传(含目录)**
- 描述:支持点击选择与拖拽两种方式;浏览器把文件分片(建议 8MB/片)PUT 到服务器,服务器顺序拼接进临时文件;目录上传时浏览器端读 `webkitRelativePath` 重建目录结构。
- 输入:文件对象(可多个)、目标网盘目录。
- 输出:临时文件路径 → 交给上游上传引擎(异步)→ 任务进入队列。
- 异常:浏览器中途中断(关页/断网)→ 服务器检测到分片流中断,丢弃半成品临时文件;单分片校验失败 → 返回该分片序号,浏览器仅重传该分片。
- 验收:①拖拽含子目录的文件夹上传后,网盘端目录层级与本地一致;②上传中途杀掉浏览器进程,60 秒内服务器临时目录无该任务的残留文件;③100MB 文件上传后网盘端大小与本地一致。

**FR-16 秒传与上传策略**
- 描述:复用上游引擎能力:默认先算 MD5 试秒传(秒传命中则**不落盘即可完成**,此时上游仅需 MD5,服务器在分片接收过程中流式计算);支持 `--norapid` 等价的"跳过秒传"开关与同名策略 skip/overwrite/rsync(映射上游 `--policy`),全局默认策略可在配置中设。
- 异常:秒传未命中 → 自动转入常规分片上传流程,用户无感。
- 验收:①上传网盘中已存在的同内容文件,任务在未接收完浏览器数据前标记"秒传成功"且总耗时 <5 秒;②策略=skip 时上传同名文件,结果为跳过且网盘原文件未变;③策略=overwrite 时网盘端文件被替换。

**FR-17 临时文件生命周期**
- 描述:上传临时文件统一放临时目录(D4);任务进入终态(成功/失败/取消)后 **10 秒内删除**;每 5 分钟扫描一次孤儿文件(无任务引用且 mtime 超过 24 小时)并删除;磁盘剩余空间低于 2GB 时暂停新任务入队并告警,已有任务继续。
- 验收:①任务成功后 10 秒内 `ls` 临时目录无对应文件;②手工放入一个 mtime=25h 前的假文件,5 分钟内被清除;③`df` 模拟剩余 <2GB 时,新上传请求被拒并提示,已运行任务完成不受影响。

### 3.5 传输任务系统(FR-18~20)

**FR-18 任务队列与并发控制**
- 描述:上传/下载统一任务模型:状态机 `排队中 → 传输中 → 成功/失败/已取消`;全局并发数可配(默认:上传 2、下载 3),超出的任务排队。
- 验收:同时提交 5 个上传,恰好 2 个进入"传输中",其余"排队中";任一完成后 1 秒内下一个自动开始。

**FR-19 进度实时展示**
- 描述:所有任务实时展示百分比、已传字节、瞬时速度、剩余时间;前端经 SSE(优先)或 WebSocket 订阅,推送间隔 ≤500ms。
- 验收:传输 100MB 文件时,界面进度数字连续增长且两次刷新间隔 ≤1 秒;速度数值与服务器日志记录均值偏差 ≤20%。

**FR-20 任务管理操作**
- 描述:对每个任务支持:取消、重试(失败任务)、清除记录;对上传支持暂停/恢复(利用队列调度);下载为直通流,暂停=取消(浏览器侧重新点下载即续传,由 Range 保证),界面需明示此差异。
- 历史持久化:任务记录(含终态)存本地 SQLite/JSON,服务重启后可见;**上传任务重启后标记为"失败(中断)"需手动重试**(上游 v4.0.0 起上传不支持断点续传,如实映射)。
- 验收:①取消排队任务立即变"已取消";②服务重启后任务列表仍在,上传中任务显示"失败(中断)";③失败任务点重试后重新入队。

### 3.6 文件管理(FR-21~24)

**FR-21 创建目录**
- 描述:映射 `mkdir`;当前目录下新建,名称合法性由上游/百度校验。
- 异常:同名目录已存在 → 返回错误提示,不产生重名目录。
- 验收:新建后列表立即出现;重名创建返回中文错误且列表不变。

**FR-22 删除**
- 描述:映射 `rm`,支持多选批量;删除进入网盘回收站(与上游一致);二次确认弹窗展示将删除的路径数量。
- 异常:任一路径不存在 → 整批返回错误(与上游行为一致,如实映射),提示具体失败项。
- 验收:批量删 3 个文件后网盘回收站出现 3 条;含不存在路径的批次整体失败且提示指明哪个路径。

**FR-23 复制**
- 描述:映射 `cp`,支持多源单目标目录。
- 验收:复制后目标目录出现同名文件,源仍在;`meta` 对比大小一致。

**FR-24 移动/重命名**
- 描述:映射 `mv`,一个入口两种语义:目标为已存在目录 → 移动;目标为同目录新名 → 重命名(与上游 CLI 语义一致)。
- 验收:移动后原目录不再有该项;重命名后仅名称变化、fs_id 不变。

### 3.7 分享与转存(FR-25~28、FR-40)

**FR-25 创建分享**
- 描述:映射 `share set`;选中文件/目录 → 弹窗设置提取码(自定义或随机 4 位)与有效天数(1/7/30/永久,以百度接口实际允许为准)→ 返回链接 + 提取码,一键复制。
- 验收:创建返回的链接在未登录浏览器中可访问且提取码有效;链接与 `share list` 中新增记录一致。

**FR-26 分享列表**
- 描述:映射 `share list`;展示分享链接、路径、状态、浏览/下载数。
- 验收:列表条数与 CLI `share list` 一致;刚创建的分享出现在列表首屏。

**FR-27 取消分享**
- 描述:映射 `share cancel <shareid>`;列表中勾选 → 批量取消,二次确认。
- 验收:取消后该链接访问返回失效;列表中状态更新为已取消。

**FR-28 转存分享链接**
- 描述:映射 `transfer <链接> [提取码]`;支持完整链接/短链/带 `?pwd=` 参数/口令文本粘贴(自动正则提取链接与提取码);目标目录为当前工作目录(与上游一致,不支持另选,界面注明)。
- 异常:提取码错误、链接失效、容量不足、含违规文件 → 分别给出对应中文提示。
- 验收:①带提取码链接转存后文件出现在当前目录;②错误提取码返回明确提示且不产生部分转存;③粘贴含中文口令的整段分享文本能自动抽取链接与密码。

**FR-40 分享链接直连下载(临时转存)**
- 描述:用户在 Web 界面粘贴分享链接(含提取码)→ 展示分享内容列表(新增分享内容浏览接口,复用上游 transfer 的链接解析与文件列举能力)→ 用户勾选文件点下载 → 系统自动将勾选项转存到自己网盘的隐藏临时目录(固定命名 `/来自分享/.tmp-<shareid>`)→ 对临时目录内文件走 FR-11 流式下载透传给浏览器 → 全部勾选文件的下载任务到达终态(成功/失败/取消)后自动删除该临时目录。用户体感为直接下载、不在网盘留存,技术上短暂占用网盘配额(界面需注明此机制)。
- 输入:分享链接(解析规则同 FR-28:完整/短链/`?pwd=`/口令文本)+ 勾选文件清单(至少 1 项,支持部分勾选)。
- 输出:浏览器开始下载(响应头语义同 FR-11,含 Range 支持);临时目录在最后一个任务终态后 10 秒内被递归删除。
- 异常分支:
  - 网盘配额不足导致转存失败 → 报错"网盘剩余空间不足,无法转存分享内容",任务终止;若百度侧已创建部分文件,回删残留,不产生孤儿临时目录;
  - 分享被百度禁止转存 → 报错"该分享不支持转存,无法直连下载",不进入下载环节、不创建临时目录;
  - 转存成功但下载中途失败或服务重启 → 运行中失败的任务终态后删除临时目录;服务启动时孤儿清理扫描器(FR-17 同一机制)额外扫描全部 `.tmp-` 前缀目录并删除;
  - 提取码错误/链接失效 → 同 FR-28 提示,不创建临时目录。
- 验收:①对含 5 个文件的分享勾选其中 2 个下载,临时目录内恰好只有这 2 个文件且下载内容完整(大小与 `meta` 一致);②全部下载完成后 10 秒内 `/来自分享/` 目录从网盘消失且 quota 已用数值回落;③预置配额不足场景后发起直连下载,得到中文报错"网盘剩余空间不足,无法转存分享内容"且网盘中无任何 `.tmp-` 残留;④对被禁止转存的分享发起直连下载,得到"该分享不支持转存,无法直连下载"提示;⑤下载中途 `kill` 服务进程,重启服务后 5 分钟内 `.tmp-` 前缀目录被孤儿清理删除(日志可查);⑥提取码错误时提示且网盘无 `.tmp-` 目录。

### 3.8 离线下载(FR-29~30)

**FR-29 添加离线任务**
- 描述:映射 `offlinedl add -path=<dir> <url...>`;支持 http/https/ftp/电驴/磁力链;支持粘贴种子文件(前端读文件内容,服务器转发给百度接口);保存路径默认当前目录,可改。
- 输出:任务 ID;多个 URL 可一次批量添加。
- 异常:任务数超百度并发上限 → 提示"离线任务数已达上限";链接协议不支持 → 指出具体哪个 URL 失败。
- 验收:①磁力链添加后返回任务 ID 且 `offlinedl list` 可见;②混合 2 有效 +1 无效 URL 提交,2 成功 1 失败且失败提示含该 URL。

**FR-30 离线任务管理**
- 描述:映射 `offlinedl list/query/cancel/delete(-all)`;列表页自动每 5 秒轮询或 SSE 推送进度(下载进度/状态);支持按 ID 精确查询、取消、删除、清空(-all 需输入确认文字"清空")。
- 验收:①任务完成后 5 秒内列表状态变为"完成";②清空操作在输入框输入"清空"前按钮禁用;③删除单条后列表立即少一条。

### 3.9 回收站(FR-31~33)

**FR-31 回收站列表**
- 描述:映射 `recycle list`(支持分页,页大小 100)。
- 验收:删除 3 个文件后列表出现 3 条;翻页参数正确传递。

**FR-32 回收站还原**
- 描述:映射 `recycle restore <fs_id...>`,按 fs_id 批量还原,二次确认。
- 验收:还原后原目录重新出现该文件,回收站少一条。

**FR-33 回收站删除/清空**
- 描述:映射 `recycle delete [-all]`;单删/批删需勾选+确认弹窗;清空(-all)需输入"清空"确认(百度侧不可恢复,最高危操作)。
- 验收:①未输入确认文字时清空按钮禁用;②清空后列表为空;③批删 2 条后剩余条数正确。

### 3.10 配置与系统(FR-34~37)

**FR-34 配置管理(Web 呈现)**
- 描述:映射 `config`/`config set`;设置页暴露安全子集:下载临时目录、上传临时目录、下载/上传全局限速(`max_download_rate`/`max_upload_rate`)、下载并发(`max_parallel`,默认 1,见 D6)、同时下载数(`max_download_load`)、上传文件并发与分片并发、同名策略(upload_policy)、下载模式(pcs/stream/locate)、user_agent(高级项,折叠)。**appid/pcs_ua/pan_ua/pcs_addr 等风控敏感项只读展示,不允许改**(改错会 403,上游也警告谨慎修改)。
- 行为:保存即写入上游兼容的配置文件;对后续任务立即生效,进行中任务不受影响。
- 验收:①设置限速 2MB/s 后新任务生效;②尝试通过 API 修改 pcs_ua 返回 403;③配置修改后重启服务,值保持。

**FR-35 通配符测试**
- 描述:映射 `match <表达式>`;设置/工具页提供输入框,返回匹配到的路径列表(只读调试用途)。
- 验收:输入 `/我的资源/*.mp4` 返回全部匹配路径,与 CLI `match` 输出集合相等。

**FR-36 服务自身状态页**
- 描述:展示服务版本、上游基线版本、运行时长、任务队列摘要、临时目录占用、磁盘剩余。不映射上游 `update`(单二进制升级由部署方替换文件,避免自更新写权限问题)与 `env`(无意义),见 3.12。
- 验收:页面显示的版本号与二进制 `--version` 输出一致;临时目录占用数值与 `du` 一致。

**FR-37 会话与登录安全**
- 描述:首次访问任意页面跳转口令登录页;口令哈希(bcrypt)存本地;会话为 HttpOnly+SameSite=Lax Cookie,有效期 7 天;连续 5 次失败锁定 5 分钟;提供"修改口令"入口;提供 `--password` / 环境变量初始化口令,未初始化时首次访问强制设置。
- 异常:Cookie 过期 → 401 跳登录页,当前 URL 记录,登录后跳回。
- 验收:①未登录直接 GET `/api/quota` 返回 401;②错误口令第 5 次起返回锁定提示;③重启服务后会话仍有效(会话密钥持久化)。

### 3.11 Web 安全(FR-38~39)

**FR-38 凭证不出服务器**
- 描述:百度凭证(BDUSS/STOKEN/Cookie)仅存服务器数据目录(0600);所有 API 响应、日志、前端 JS 上下文中不得出现明文凭证;日志中的 Cookie 一律脱敏为前 4 后 4 字符。
- 验收:①`grep -r BDUSS` 前端产物目录无命中;②日志文件中凭证字段均为脱敏格式;③浏览器查看全部网络响应无明文凭证。

**FR-39 API 防护基线**
- 描述:全部 `/api/*` 需会话(登录接口除外);写操作(删/移/分享/清空)统一 POST/DELETE;下载代理 URL 带 30 分钟有效期的签名 token,防 CSRF 直链外泄;登录与上传接口限速(每 IP 10 次/分钟)。
- 验收:①未带会话的写请求一律 401;②下载签名 token 过期后返回 403;③对登录接口 1 分钟发 11 次请求,第 11 次被限流。

### 3.12 CLI→Web 命令映射与降级说明

以 v4.0.2 README 命令清单逐条核对。**完整映射**:login(FR-01)、loglist/who(FR-02)、su(FR-03)、logout(FR-04)、quota(FR-05)、cd/pwd(FR-07)、ls(FR-06)、tree(FR-08)、meta(FR-09)、search(FR-10)、download(FR-11/12/14)、upload(FR-15/16)、locate(经 FR-11 的直链机制内部实现)、export(FR-13)、mkdir(FR-21)、rm(FR-22)、cp(FR-23)、mv(FR-24)、share set/list/cancel(FR-25~27)、transfer(FR-28;FR-40 直连下载复用其链接解析——FR-28 为手动转存到当前目录并保留文件,FR-40 为自动临时转存+流式下载+即删,两者并存)、offlinedl add/query/list/cancel/delete(FR-29/30)、recycle list/restore/delete(FR-31~33)、config/config set(FR-34)、match(FR-35)、tool 加解密(不单独建 UI,FR-35 同页提供入口,验收:能对 1KB 文件完成加密再解密且内容一致)。

**降级/不提供项及理由**:

| CLI 能力 | Web 端处理 | 理由 |
|---|---|---|
| `login` 交互式用户名密码 | 不提供,仅 Cookie/BDUSS+STOKEN | 上游自述"已长期不维护,不推荐";需图形验证码多轮交互,Web 化成本高且成功率低 |
| `update` 在线更新 | 不提供 | 单二进制自更新需要写自身文件权限,与部署方式冲突;状态页显示版本提示手动升级 |
| `env` 环境变量展示 | 不提供 | 终端环境信息对浏览器用户无意义 |
| `--status` 线程级状态 | 降级为任务级进度 | 线程级调试信息对普通用户是噪音;任务级已满足"体感"要求 |
| 下载断点续传(服务端持久化) | 改为浏览器 Range 续传 | 下载不落盘,服务器无法存续传点;浏览器下载管理器天然支持 Range 恢复,体感等价 |
| Tab 自动补齐/仿 shell 交互 | 不适用 | 图形界面以搜索+面包屑导航覆盖同场景 |
| 上传断点续传 | 不支持,如实映射 | 上游 v4.0.0 起因官方接口变化已移除上传断点续传;中断任务标记失败,手动重传 |
| 秒传转存/export 实用性 | 保留入口+风险声明 | 上游声明官方已封禁秒传,成功率不作承诺 |

## 4. 非功能需求

**NFR-01 传输性能**:下载代理单流在 1Gbps 局域网内 ≥80MB/s(受百度侧限速时以百度为准,不作承诺);同机回环 API 响应(list/quota 等)P95 ≤500ms(不含百度接口自身延迟)。上传受百度接口与账号策略约束,验收只测"分片接收速率 ≥50MB/s(浏览器→服务器,1Gbps 局域网)"。
**NFR-02 实时性**:进度推送间隔 ≤500ms;操作反馈(增删改)界面刷新 ≤1 秒。
**NFR-03 内存预算**:空载 RSS ≤100MB;单文件下载流式转发附加内存 ≤64MB(缓冲+TLS);10 并发传输下 RSS ≤500MB。
**NFR-04 磁盘预算**:除上传临时文件(FR-17 生命周期约束)与程序数据(配置+凭证+任务库)≤50MB 外,不留任何增长性文件;下载全程临时目录增长 ≤32MB/任务。
**NFR-05 平台与交付**:目标 `linux/amd64`、`linux/arm64`,CGO_ENABLED=0 静态编译,单二进制 + 内嵌前端(go:embed);内核 ≥3.10;交付物:两个二进制 + 一份 README。
**NFR-06 可靠性**:服务崩溃或被 kill 后重启,配置/凭证/任务历史不丢失;上传临时文件在下次启动时按孤儿规则清理;监听端口被占时报错退出并给出明确提示,不做静默换端口。
**NFR-07 日志**:分级(DEBUG/INFO/WARN/ERROR),默认 INFO 落 stdout,可选文件输出带 10MB×3 轮转;日志含任务 ID 串联,凭证脱敏(FR-38)。
**NFR-08 安全**:口令 bcrypt 存储;会话 Cookie HttpOnly+SameSite=Lax;凭证文件 0600;无 shell 注入面(不调用外部命令);目录遍历防护(上传目标路径规范化,拒绝 `..`)。
**NFR-09 兼容浏览器**:Chrome/Edge/Firefox 近两年主版本;移动端浏览器尽力而为,不写验收。
**NFR-10 上游升级**:上游代码以库形式 import(不 fork),锁定 v4.0.2(D9);升级上游版本需回归 FR-01/06/11/15 四条冒烟用例。

## 5. 硬件与运行资源

软件为服务端常驻进程,无直接硬件外设占用;资源口径如下(需求基线,设计阶段细化):

| 项目 | 要求 |
|---|---|
| CPU | x86_64 或 arm64,≥2 核;传输时段平均占用 ≤50%(2 核基线),主要为 TLS 与流式拷贝 |
| 内存 | 见 NFR-03(空载 ≤100MB,10 并发 ≤500MB) |
| 存储 | 程序数据 ≤50MB;上传临时目录需可容纳最大单任务文件(理论上限 128GB,由磁盘水位 FR-17 兜底);建议数据盘预留 ≥10GB |
| 网络 | 需可访问 `pan.baidu.com` 及 PCS 上传域(动态获取);监听 TCP 端口默认 8080(可配),局域网可达 |
| 接口占用 | 无 GPIO/串口/中断需求(纯网络服务) |

| 写操作 | `/api/files/mkdir` `/rm` `/cp` `/mv` | POST | FR-21~24 |
| 上传 | `/api/upload/init` → `/api/upload/chunk` → `/api/upload/complete` | POST | FR-15 |
| 下载 | `/api/dl?path=&token=`(30min 签名) | GET(Range) | FR-11 |
| 任务 | `/api/tasks` `/api/tasks/{id}/cancel` `/retry`;`/api/events`(SSE) | GET/POST | FR-18~20 |
| 分享 | `/api/share/set` `/api/share/list` `/api/share/cancel` | GET/POST | FR-25~27 |
| 转存 | `/api/transfer` | POST | FR-28 |
| 分享内容浏览/直连下载 | `/api/share/preview`(列表)、`/api/share/dl?path=&token=`(Range 下载,签名 token 同 FR-11) | POST/GET | FR-40 |
| 离线 | `/api/offline/add` `/list` `/query` `/cancel` `/delete` | GET/POST | FR-29/30 |
| 回收站 | `/api/recycle/list` `/restore` `/delete` | GET/POST | FR-31~33 |
| 配置 | `/api/config` `/api/config/set` | GET/POST | FR-34 |
| 工具 | `/api/match` `/api/export` `/api/tool/cipher` | POST | FR-13/35 |

关键约定:
- 上传三段式:`init` 携带文件名/大小/相对路径/目标目录,返回任务 ID 与分片大小;`chunk` 携带序号与二进制体,支持按序号重传;`complete` 触发秒传探测→引擎上传。
- 下载签名 token 绑定"路径+过期时间+会话",防 CSRF 与链接外流。
- SSE `task` 事件载荷:`{task_id, kind, state, percent, speed_bps, eta_sec, error}`。
- 分页:文件列表 page/page_size(默认 100,上限 1000),与上游 >1000 对象目录兼容。

## 7. 范围外(Non-Goals)

- NG-01 不逆向百度私有加密协议,不实现超出上游 BaiduPCS-Go 已有能力的接口调用。
- NG-02 不做 Web 端多用户体系与权限分级(单口令共享使用,D1)。
- NG-03 不做 iOS/Android 原生 App 或打包(移动浏览器尽力而为)。
- NG-04 不做音视频在线转码播放、图片缩略图转码(百度私有转码接口不在上游能力内);详情面板可展示 MD5 等元信息。
- NG-05 不做公网部署配套(HTTPS 终结、反代配置、DDNS),文档仅给建议。
- NG-06 不做在线自更新(NFR-05 交付形态决定)。
- NG-07 不承诺突破百度账号限速,任何"提速"预期以上游声明为准。
- NG-08 不做服务器端 zip 打包下载(FR-12 决策)。
- NG-09 不做多实例互斥/分布式部署;单机单进程。

## 8. 风险与预期管理

| # | 风险 | 影响 | 需求侧对策 |
|---|---|---|---|
| R1 | 百度风控/接口变动导致上游能力失效(历史上秒传、上传断点续传均因此丧失) | 个别 FR 失效 | 锁定上游版本(D9);文档明示"功能性依赖上游,失效时降级而非缺陷";验收以锁定版本为准 |
| R2 | 账号限速:非 SVIP 调大并发触发账号级限速数小时~数天 | 用户体验骤降 | D6 默认 max_parallel=1;设置页对调大并发展示上游原文警告 |
| R3 | 服务器中转下载占用本地带宽与 TLS 开销 | 局域网/本机负载 | NFR-01/03 量化指标;限速可配(FR-34) |
| R4 | 上传临时目录磁盘写满 | 任务失败、磁盘抖动 | FR-17 水位 2GB 暂停入队 + 孤儿清理;FR-16 秒传命中不落盘减少峰值占用 |
| R5 | 凭证(BDUSS 等同账号全权)泄漏 | 账号被完全控制 | FR-38/NFR-08 全链路不落浏览器;文档明示口令泄露风险等同账号风险 |
| R6 | 浏览器大文件上传内存占用(分片策略不当) | 服务 OOM | 分片 8MB 流式拼接;NFR-03 内存预算约束,设计阶段验证 |
| R7 | dlink UA 伪装策略变动(403) | 下载通道失效 | 列为冒烟用例(FR-11);user_agent 可配(FR-34 高级项)作为应急手段 |
| R8 | 中文文件名跨浏览器乱码 | 下载文件名损坏 | RFC 5987 `filename*` 编码写入验收标准(FR-11) |
| R9 | 非常规字符路径(引号/百分号/`..`)注入 | 安全漏洞/操作失败 | NFR-08 路径规范化;上传前名称合法性校验(上游有同款检测) |
| R10 | FR-40 临时转存短暂占用网盘配额,大体积分享或并发多个直连下载会挤占正常配额 | 期间其他上传/转存可能因配额不足失败 | 界面明示短暂占用机制(FR-40 描述);转存前预检配额(FR-40 异常分支 1);临时目录用后即删 |
| R11 | 部分分享被百度侧禁止转存,直连下载不可用 | FR-40 对该类分享完全失效 | 明确报错文案(FR-40 异常分支 2);界面引导改用 FR-28 手动转存(若允许)或官方渠道 |
